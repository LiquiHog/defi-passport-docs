# About This Repository

Thank you for your interest in DeFi Passport.

## Important notice

**This repository is not open for contributions.**

DeFi Passport is a proprietary project owned and maintained exclusively by
LiquiHog. This repository publishes its **documentation** for reference. The
contract source, compiled programs, and automation code are not published here
and are not planned for release.

## What this means

| | |
|---|---|
| **No pull requests** | We do not accept external contributions or pull requests |
| **No forks for distribution** | Forking for redistribution or commercial use is prohibited |
| **Read and learn** | You are welcome to read the documentation and build against the public SDKs |
| **Report issues** | Issues are welcome and genuinely useful - see below |

## Reporting issues

Issues are the one form of contribution we do want, and there are three kinds
worth opening.

**A documentation error.** Something here is wrong, out of date, or contradicts
what the contracts actually do. These are the most valuable reports we get. Use
the documentation issue template and quote the passage.

**Behaviour that does not match the docs.** DeFi Passport did something other than
what is written here. Use the bug report template. A transaction id is usually
enough for us to look it up.

**A question the docs should have answered.** If you had to ask, the page you
looked at has a gap. Say which page you tried - that tells us where to fix it.

Please do not open a pull request to fix an issue. We will address reports
internally.
